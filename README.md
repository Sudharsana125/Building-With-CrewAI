## About CrewAI

CrewAI is a Python framework for building and orchestrating AI agents that can work together to accomplish tasks.

It provides the building blocks needed to create agentic workflows, where different agents can have specific roles, goals, and responsibilities.

The core concepts I am exploring include:

- Agents
- Tasks
- Crews
- Processes
- Tools
- Multi-Agent Systems
- Memory & Knowledge
- Flows
- RAG with CrewAI
- Real-world Agentic AI applications
